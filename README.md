# fastfood_gui.py

A simple graphical interface for placing fast-food orders, built with Python and Tkinter.

## Features

- Browse menu items across four categories: **Burgers**, **Sides**, **Drinks**, and **Desserts**
- Set quantities for each item using a spin-box control
- Live order summary that updates as you make selections
- Enter your name and submit your order to receive a confirmation
- Clear the entire order with one click

## Requirements

- Python 3.10 or later
- Tkinter (included in the Python standard library)
  - On Ubuntu/Debian you may need: `sudo apt-get install python3-tk`

## Running the app

```bash
python fastfood_gui.py
```

## Running the tests

```bash
python -m pytest tests/
```
